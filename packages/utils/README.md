# @svelte-draw/utils

Framework-neutral TypeScript library of svelte-draw (export and geometry utilities (exportToSvg, exportToCanvas, hit testing)), derived from [Excalidraw](https://github.com/excalidraw/excalidraw) (MIT).

This is a workspace package of this repository, consumed from source via the `workspace:*` protocol; it is not published to npm. Import it from other workspace packages:

```ts
import {} from "@svelte-draw/utils";
```
